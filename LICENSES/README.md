# Licences

The full texts of every licence the game's content, engine and font are under. `ASSETS.md` lists each
asset with its author, source and licence; the in-game Credits screen (login screen or the in-game
menu) shows the same list and these texts, built by `tools/sync_client_content.py`.

| File | Covers |
|---|---|
| `CC-BY-4.0.txt` | The Polyfork characters, monsters, townsfolk, animals and environment parts (each credited by name in its folder's `LICENSE.txt` and on the Credits screen) |
| `CC0-1.0.txt` | The Quaternius animation clips, all music, ambience, footsteps and sound effects from OpenGameArt, and everything this project generated (icons, sounds, the procedural models, the application icon) |
| `OFL-1.1-OpenSans.txt` | Open Sans, the UI font Godot ships |
| `Godot-LICENSE.txt`, `Godot-COPYRIGHT.txt` | Godot Engine (MIT) and the third-party code it includes |

The project's own source code has no licence yet (see README.md).
